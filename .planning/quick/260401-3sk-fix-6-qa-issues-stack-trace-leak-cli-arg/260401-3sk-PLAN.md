**ISSUE-001 -- Move arg parsing inside try/catch:**
In bin/cli.mjs, restructure the `main()` function so the ENTIRE arg-parsing loop (lines 30-69) runs inside the try/catch block, not just the dispatch section. The simplest approach: move the `try {` to BEFORE the for-loop (before line 30). The existing catch at line 102 already prints `Error: ${err.message}` which is exactly what we want. Remove the duplicate inline error exits for `--timeout` missing value (line 58-59) and unknown argument (lines 66-68) -- instead, throw errors that the catch block handles. Also throw for missing binPath (lines 71-75) so all errors flow through one catch. The printUsage() calls in the catch should only trigger for usage-type errors.

Concrete restructuring of main():
```

  const args = process.argv.slice(2);

  let mode = 'wrap';
  let timeout = 5;

    for (let i = 0; i < args.length; i++) {
      // ... same logic but throw errors instead of console.error + process.exit
```

**ISSUE-003 -- Add explicit SIGTERM/SIGINT forwarding in wrapper template:**
In lib/wrap.js, add signal handlers in the WRAPPER_TEMPLATE perl section, right after the `$SIG{ALRM}` line and before `alarm $timeout;`:
```perl
$SIG{TERM} = sub { kill('TERM', -$pid); exit(143); };
$SIG{INT}  = sub { kill('INT',  -$pid); exit(130); };
```
Exit codes: 143 = 128 + 15 (SIGTERM), 130 = 128 + 2 (SIGINT). Use kill with signal name as string for clarity. The `-$pid` targets the process group (child called setpgid(0,0) so it is its own group leader; killing the group ensures any grandchildren also receive the signal).

The resulting perl signal section should be:
```perl
$SIG{ALRM} = sub { kill 9, -$pid };
$SIG{TERM} = sub { kill('TERM', -$pid); exit(143); };
$SIG{INT}  = sub { kill('INT',  -$pid); exit(130); };
alarm $timeout;
waitpid($pid, 0);
```

2. **Signal forwarding: SIGTERM** (ISSUE-005):
```javascript
test('SIGTERM is forwarded to child process', async () => {
  const bin = createTestBinary('sigterm-test', '#!/bin/sh\ntrap "" TERM\nsleep 30\n');
  await wrap(bin, 30); // long timeout so SIGALRM doesn't interfere

  const child = spawn(bin, [], { env: process.env, stdio: ['pipe', 'pipe', 'pipe'] });
  // Wait briefly for the child to start and trap TERM
  await new Promise(r => setTimeout(r, 300));

  child.kill('SIGTERM');
  const { exitCode } = await new Promise(resolve => {
    child.on('close', code => resolve({ exitCode: code }));
  });

  // If signal forwarding works, the process group gets SIGTERM.
  // The child traps TERM but the wrapper parent exits 143.
  // If the child doesn't die from TERM (it traps it), the wrapper still exits.
  // The exit code should be 143 (wrapper got SIGTERM) or the child's exit if TERM propagated.
  expect([143, 128 + 15]).toContain(exitCode);
}, 10_000);
```
