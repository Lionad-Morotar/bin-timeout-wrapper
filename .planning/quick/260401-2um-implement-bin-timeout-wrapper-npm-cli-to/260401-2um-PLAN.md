   - `BACKUP_SUFFIX`: constant `_backup`
   - All functions throw with descriptive messages (CLI catches and prints).

Import style: use `import.meta.url` with `fileURLToPath` for path resolution where needed. Use `node:fs` and `node:path` imports.

<task type="auto" tdd="true">
  <name>Task 2: Implement wrap, restore, status modules and wrapper template</name>
  <files>lib/template.sh, lib/wrap.js, lib/restore.js, lib/status.js</files>
  <behavior>
    - Wrap `sleep 10` with 5s timeout -> process killed after ~5s, exit code 137
    - Wrap `echo` with 5s timeout -> completes normally, stdout passes through, exit code 0
    - Wrap already-wrapped binary -> throws error about duplicate wrap
    - Restore wrapped binary -> original binary restored, works normally
    - Restore unwrapped binary -> throws error about no backup
    - Status on wrapped binary -> returns { wrapped: true, timeout: N, backup: path }
    - Status on unwrapped binary -> returns { wrapped: false }
    - BIN_TIMEOUT env var overrides default timeout in wrapper script
  </behavior>
  <action>
1. **lib/template.sh**: The wrapper shell script template. Use literal template string (not a file read) with placeholders `{bin_path}`, `{timeout}`:
   ```sh
   #!/bin/sh
   # Auto-generated by @lionad/bin-timeout-wrapper
   # Wraps: {bin_path}_backup
   # Timeout: {timeout}s (override with BIN_TIMEOUT env var)

   TIMEOUT="${BIN_TIMEOUT:-{timeout}}"
   exec perl -e '
     $SIG{ALRM} = sub { kill 9, $$ };
     alarm $ENV{TIMEOUT} || $ARGV[0];
     exec @ARGV;
   ' "$TIMEOUT" "{bin_path}_backup" "$@"
   ```
   Note the `$SIG{ALRM} = sub { kill 9, $$ }` ensures SIGKILL (exit 137) on timeout. The `exec @ARGV` replaces the perl process with the actual binary for clean signal handling.

2. **lib/wrap.js**: Export async function `wrap(binPath, timeout)`:
   - Call `resolveBinPath(binPath)` to validate
   - Call `isWrapped(binPath)` to check for duplicate wrap -- if true, throw `"Already wrapped: ${binPath}"`
   - Compute backup path: `binPath + BACKUP_SUFFIX`
   - If backup already exists, throw `"Backup already exists: ${backupPath}. Remove it or restore first."`
   - `fs.renameSync(binPath, backupPath)` -- rename original to backup
   - Generate wrapper content from template, replacing `{bin_path}` and `{timeout}` placeholders
   - `fs.writeFileSync(binPath, wrapperContent, 'utf-8')`
   - `fs.chmodSync(binPath, 0o755)` -- ensure executable
   - Return `{ binPath, backupPath, timeout }`

3. **lib/restore.js**: Export async function `restore(binPath)`:
   - Call `resolveBinPath(binPath)` to validate (the current file, which is the wrapper)
   - Compute backup path: `binPath + BACKUP_SUFFIX`
   - If backup doesn't exist, throw `"No backup found at ${backupPath}"`
   - `fs.unlinkSync(binPath)` -- remove wrapper script
   - `fs.renameSync(backupPath, binPath)` -- restore original
   - Return `{ binPath, restoredFrom: backupPath }`

4. **lib/status.js**: Export async function `status(binPath)`:
   - Call `resolveBinPath(binPath)` to validate
   - Compute backup path
   - Check `isWrapped(binPath)`
   - If wrapped, extract timeout from the `# Timeout: Ns` comment line (regex: `/Timeout: (\d+)s/`)
   - Return object: `{ wrapped, binPath, timeout?, backupPath? }`

All modules use synchronous fs operations (wrap/restore are file system state mutations, simplicity over async here).
