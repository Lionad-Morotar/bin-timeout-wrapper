## Key Interactions to Verify

- `npx @lionad/bin-timeout-wrapper --timeout 5 -- /path/to/bin` wraps a binary
- `npx @lionad/bin-timeout-wrapper --restore -- /path/to/bin` restores original
- `npx @lionad/bin-timeout-wrapper --status -- /path/to/bin` shows wrap status
- Wrapped binary completes normally within timeout → correct exit code
- Wrapped binary exceeds timeout → SIGKILL, exit 137
- BIN_TIMEOUT env var overrides default timeout
- BIN_TIMEOUT=0 disables timeout
- SIGTERM to wrapper → forwarded as SIGTERM to child
- SIGINT to wrapper → forwarded as SIGINT to child
- Duplicate wrap → error message
- Binary path with spaces → works correctly
- Binary path is symlink → works correctly

## Edge Cases

- Binary doesn't exist at specified path → clear error
- Binary is a directory → clear error
- Permission denied on binary path → clear error
- _backup file already exists → handle collision
- BIN_TIMEOUT=abc (non-numeric) → handle gracefully
- fork() fails (unlikely but possible) → error message
- exec fails in child (binary not found after rename) → error message
- Rapid wrap/restore/wrap sequence → no state corruption

## Critical Paths

1. **Core timeout flow (E2E):** Wrap `sleep 10` with 5s timeout → verify SIGKILL after 5s → exit code 137
2. **Normal execution flow (E2E):** Wrap `echo hello` with 5s timeout → verify stdout passes through → exit code 0
3. **Signal forwarding (E2E):** Wrap long-running process → send SIGTERM to wrapper → verify child receives SIGTERM
4. **Restore flow:** Wrap → verify status shows wrapped → restore → verify status shows unwrapped → verify binary works
5. **VS Code integration (manual):** Wrap rg with 5s timeout → search in VS Code → verify search works normally

## Test Framework

- Unit tests: vitest (ESM native support)
- E2E tests: vitest + child_process.spawn for real process testing
- All perl wrapper tests must use real processes (signals cannot be mocked)
